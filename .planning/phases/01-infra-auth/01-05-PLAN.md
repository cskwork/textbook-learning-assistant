**구축된 기능:**
Phase 1 전체: 모노레포 인프라, JWT 인증 API (회원가입/로그인/세션유지/로그아웃), 온보딩 역할 선택, 역할별 보호 라우트, 반응형 앱 셸 (하단 탭바 + 사이드바)

**사전 준비:**
- PostgreSQL이 실행 중인지 확인
- 터미널 1: `pnpm --filter api dev` (localhost:3000)
- 터미널 2: `pnpm --filter web dev` (localhost:5173)

**테스트 1: 회원가입 + 온보딩 (AUTH-01, AUTH-05)**
1. http://localhost:5173 접속
2. /login 페이지로 리디렉트되는지 확인
3. "계정이 없으신가요?" 링크로 /register 이동
4. 이메일 + 비밀번호(8자 이상) 입력 후 가입
5. /onboarding 페이지로 이동하는지 확인
6. "학생" 카드 클릭
7. /student 홈으로 이동하고 학생용 메뉴가 표시되는지 확인

**테스트 2: 세션 유지 (AUTH-03)**

**테스트 3: 로그아웃 (AUTH-04)**
10. 로그아웃 버튼 클릭
11. /login 페이지로 이동하는지 확인

**테스트 4: 로그인 + 에러 메시지 (AUTH-02)**

14. 올바른 이메일 + 비밀번호 → /student 홈 이동

**테스트 5: 강사 계정 (AUTH-05)**
