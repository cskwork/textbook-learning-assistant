1. apps/web/src/lib/api.ts 생성:
   - fetch wrapper 함수: credentials 'include' 자동 포함 (httpOnly cookie 전송)
   - baseURL: import.meta.env.VITE_API_URL || 'http://localhost:3000'
   - 401 응답 시 자동으로 /api/auth/refresh 호출 → 실패 시 로그인 페이지로 리디렉트
   - JSON request/response 자동 처리

2. apps/web/src/lib/auth.ts 생성:
   - API 호출 함수들: register(email, password), login(email, password), logout(), refreshToken(), getMe(), setRole(role)
   - 각 함수는 api.ts의 fetch wrapper 사용

3. apps/web/src/contexts/AuthContext.tsx 생성:
   - AuthContext: user(User | null), isLoading(boolean), login, logout, setRole 함수
   - AuthProvider: 앱 마운트 시 getMe()로 현재 사용자 로드 (세션 유지 — AUTH-03)
   - 로딩 중 스피너 또는 스켈레톤 표시
   - logout 함수: API 호출 → user null로 설정 → /login으로 navigate

4. apps/web/src/routes/register.tsx (회원가입 페이지):
   - shadcn Card + Form 레이아웃
   - 이메일 입력 (Input), 비밀번호 입력 (Input type=password)
   - 비밀번호 8자 이상 클라이언트 검증 + 서버 에러 표시
   - 제출 시 auth.register 호출 → 성공 시 /onboarding으로 이동
   - 에러 시 폼 하단에 빨간색 에러 메시지 표시
   - "이미 계정이 있으신가요?" → /login 링크
   - 반응형: 모바일에서 전체 너비, 태블릿/데스크톱에서 중앙 카드 (max-w-md mx-auto)
   - 파란색 계열 교육 앱 느낌의 디자인 (앱 로고/이름 상단)

5. apps/web/src/routes/login.tsx (로그인 페이지):
   - register.tsx와 동일한 레이아웃 패턴
   - 이메일 + 비밀번호 입력
   - 제출 시 auth.login 호출
   - 서버에서 반환하는 구체적 에러 메시지 그대로 표시: "가입되지 않은 이메일입니다", "비밀번호가 틀렸습니다"
   - 성공 시: isOnboarded=false → /onboarding, isOnboarded=true → / (홈)
   - "계정이 없으신가요?" → /register 링크

6. apps/web/src/routes/onboarding.tsx (역할 선택 페이지):
   - 큰 카드 2개: 학생(Student) / 강사(Instructor)
   - 각 카드에 아이콘 + 설명 텍스트
   - 클릭 시 auth.setRole 호출 → 성공 시 역할별 홈으로 이동
   - 반응형: 모바일에서 세로 배치, 태블릿에서 가로 배치
   - 이미 온보딩 완료된 사용자가 접근하면 홈으로 리디렉트
  </action>
  <verify>

    2. /login 페이지에서 로그인 폼이 렌더링되고 에러 메시지 표시
    3. /onboarding 페이지에서 학생/강사 카드가 표시됨
    4. 새로고침 후 AuthContext가 세션을 복원 (getMe 호출)
