<task type="auto">
  <name>Task 2: Drizzle DB 스키마 + Express 5 서버 기초</name>
  <files>
    apps/api/drizzle.config.ts
    apps/api/src/db/schema.ts
    apps/api/src/db/index.ts
    apps/api/src/middleware/errorHandler.ts
    apps/api/src/index.ts
  </files>
  <action>
1. apps/api/drizzle.config.ts 생성:
   - dialect: 'postgresql'
   - schema: './src/db/schema.ts'
   - out: './drizzle'
   - dbCredentials: { url: process.env.DATABASE_URL! }

2. apps/api/src/db/schema.ts 생성 (RESEARCH.md Pattern 1 기반):
   - userRoleEnum: pgEnum('user_role', ['student', 'instructor'])
   - users 테이블: id(generatedAlwaysAsIdentity), email(varchar 255 unique notNull), passwordHash(text notNull), role(userRoleEnum nullable — 온보딩 전 null), isOnboarded(boolean default false notNull), createdAt, updatedAt (둘 다 timestamp withTimezone defaultNow)
   - refreshTokens 테이블: id(generatedAlwaysAsIdentity), userId(integer references users.id onDelete cascade), token(text unique notNull), expiresAt(timestamp withTimezone notNull), createdAt(timestamp withTimezone defaultNow)

3. apps/api/src/db/index.ts 생성:
   - dotenv/config import (최상단)
   - drizzle-orm/node-postgres에서 drizzle import
   - `export const db = drizzle(process.env.DATABASE_URL!)` — Drizzle v1 간결 연결 방식
   - schema도 함께 export: `import * as schema from './schema'` → `export { schema }`

4. apps/api/src/middleware/errorHandler.ts 생성:
   - Express 5 글로벌 에러 핸들러: 반드시 (err, req, res, next) 4개 파라미터
   - NODE_ENV === 'development'일 때 stack trace 포함, 아니면 제외
   - JSON 응답: { error: err.message }

5. apps/api/src/index.ts 생성:
   - dotenv/config 최상단 import
   - express import, cors, cookie-parser import
   - express.json(), cors({ origin: process.env.CORS_ORIGIN, credentials: true }), cookieParser() 미들웨어 등록
   - GET /health 라우트: { status: 'ok', timestamp: new Date().toISOString() } 응답
   - errorHandler 미들웨어 등록 (라우트 뒤에)
   - PORT 환경변수로 서버 시작, console.log로 기동 메시지

6. drizzle-kit generate --name=init 실행하여 마이그레이션 SQL 파일 생성 (DB 연결 없이도 가능)
   - 주의: 실제 DB 마이그레이션 적용(drizzle-kit migrate)은 DB가 실행 중이어야 하므로, 마이그레이션 파일 생성까지만 이 태스크에서 수행
  </action>
  <verify>

    2. drizzle-kit generate가 성공하여 apps/api/drizzle/ 폴더에 SQL 마이그레이션 파일이 생성됨
    3. tsx apps/api/src/index.ts 실행 후 curl http://localhost:3000/health 가 { "status": "ok" } 반환 (DB 없이도 서버 기동 확인)
