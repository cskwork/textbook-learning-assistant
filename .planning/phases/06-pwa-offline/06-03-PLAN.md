    Phase 6 PWA 오프라인 지원 전체 구현:

    - PWA 아이콘 3종 (192×192, 512×512, apple-touch-icon 180×180)

    - vercel.json SPA rewrites + sw.js Cache-Control
    - PWAInstallBanner 컴포넌트 (업데이트/오프라인준비/설치유도 3개 상태)
    - main.tsx에 PWAInstallBanner 통합

  <how-to-verify>
    **준비:**
    - `pnpm run build --filter web && pnpm --filter web exec vite preview --port 4173` 실행
    - Chrome 브라우저에서 http://localhost:4173 열기

    **체크리스트:**

    **1. Service Worker 등록 확인**
    - Chrome DevTools (F12) → Application → Service Workers
    - "sw.js" 상태가 "activated and running" 인지 확인
    - ✅ 또는 ❌ 기록

    **2. Manifest 확인**
    - Application → Manifest
    - name: "수학 기출 학습 도우미" 표시 여부
    - icons 2개 표시 여부
    - display: "standalone" 여부
    - ✅ 또는 ❌ 기록

    **3. 오프라인 테스트**
    - Application → Service Workers → "Offline" 체크박스 ON
    - 페이지 새로고침 → 앱이 로드되면 ✅
    - /student/problems 경로로 이동 후 새로고침 → 로드되면 ✅ (navigateFallback 동작)
    - "Offline" 체크박스 OFF

    **4. Cache Storage 확인**
    - Application → Cache Storage
    - "workbox-precache-..." 캐시 존재 여부
    - JS/CSS/HTML 파일들이 캐시에 있는지 확인
    - ✅ 또는 ❌ 기록

    **5. Lighthouse PWA 점수 (선택)**
    - F12 → Lighthouse → Progressive Web App → Analyze
    - Installability: "Installable" 여부 (필수 아이콘 + manifest 조건)
    - 점수 기록 (참고용)

    **6. PWAInstallBanner 동작 (오프라인 알림)**
    - 새 시크릿 창에서 http://localhost:4173 열기
    - 3초 후 녹색 "오프라인에서도 사용 가능합니다" 알림이 하단에 표시되면 ✅
