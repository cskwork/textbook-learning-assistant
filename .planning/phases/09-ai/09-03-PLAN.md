### 1. student-detail.tsx 생성

`apps/web/src/routes/instructor/groups/student-detail.tsx` 를 새로 생성한다.

라우트 파라미터: `useParams<{ id: string; studentId: string }>()` — groupId = Number(id), studentId = string

페이지 제목: "학생 상세 분석" + 뒤로가기 버튼(ArrowLeft) → `/instructor/groups/${groupId}/report`

데이터 로드 (useEffect):
1. `getGroup(groupId)` — 그룹 정보 (강사 소유 확인)
2. `getCategoryAccuracy(studentId)` — BarChart 데이터
3. `getWeakCategories(studentId)` — RadarChart 데이터
4. `getOverallStats(studentId)` — 통계 카드
5. `db.wrongNotes.where('studentId').equals(studentId).limit(5).toArray()` — 오답노트 최근 5개
6. 학생 이름: `MOCK_STUDENTS.find(s => s.email === studentId)?.name ?? studentId`

사전 조사 — SummaryStatsCards prop 인터페이스:
`apps/web/src/components/analytics/SummaryStatsCards.tsx` 를 먼저 읽어 정확한 prop 타입(예: `stats`, `streak`, `overall` 등)을 확인한다. streak prop이 필수라면 0값 또는 더미 StreakData로 대체하고, props 불일치 시 인라인 stat 카드 4개로 직접 렌더링한다(기존 그룹 리포트 stat-accent-blue/emerald/amber/rose 패턴 재사용).

import 목록:
- `AccuracyBarChart` from `@/components/analytics/AccuracyBarChart`
- `WeakTypeRadarChart` from `@/components/analytics/WeakTypeRadarChart`
- `SummaryStatsCards` from `@/components/analytics/SummaryStatsCards`
- `getCategoryAccuracy, getWeakCategories, getOverallStats` from `@/services/analytics.service`
- `getGroup, MOCK_STUDENTS` from `@/services/group.service`
- `db` from `@/lib/db`
- 기존 UI 컴포넌트: Card, CardContent, CardHeader, CardTitle, Button, Badge, ArrowLeft (lucide-react), Link, useParams, useNavigate, useEffect, useState, useAuth

페이지 레이아웃 (기존 분석 대시보드 스타일 참조):
```
┌─ 헤더 (뒤로가기 + "학생 상세 분석" + 학생 이름/이메일) ─┐
├─ SummaryStatsCards (전체 통계 4종) ──────────────────────┤
├─ 2컬럼 그리드 ────────────────────────────────────────────┤
│  ├─ AccuracyBarChart (유형별 정답률) ──────────────────   │
│  └─ WeakTypeRadarChart (취약 유형 레이더) ─────────────   │
├─ 최근 오답노트 카드 ──────────────────────────────────────┤
│  오답 5개 목록 (문제 내용 앞 50자, 유형, 마지막 오답일)   │
└───────────────────────────────────────────────────────────┘
```

오답노트 섹션:
- Card > CardHeader ("최근 오답노트") > CardContent
- wrongNotes.map()으로 각 항목 렌더링: `db.questions.get(note.questionId)` 로 문제 content 로드 필요
- 간단하게: wrongNotes 배열을 map하되 questionId, category, wrongCount, lastWrongAt만 표시 (content 비동기 로드 생략)
- 오답 없을 때: "오답 기록이 없습니다" 빈 상태

SummaryStatsCards 타입:
- `OverallStats` = `{ total: number; accuracy: number; totalTimeSeconds: number }`
- `StreakData` = `{ current: number; best: number; lastStudiedAt: number }`
- StreakData는 의존성이 복잡하므로 생략하고 overall stats만 표시, 또는 0값으로 대체

만약 SummaryStatsCards가 streak을 필수 prop으로 받는다면, overall stats 기반으로 직접 4개 stat 카드를 인라인으로 렌더링한다 (기존 그룹 리포트의 stat 카드 패턴 재사용: stat-accent-blue/emerald/amber/rose).

로딩 스켈레톤: isLoading 상태에서 pulse 애니메이션 div 4개 그리드.
