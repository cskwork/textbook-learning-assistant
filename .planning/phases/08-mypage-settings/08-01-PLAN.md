    2. `apps/web/src/contexts/SettingsContext.tsx` 생성:
       - `SettingsContextValue` 인터페이스: `isDarkMode: boolean`, `katexFontSize: number`, `toggleDarkMode: (enabled: boolean) => void`, `setKatexFontSize: (size: number) => void`
       - localStorage 키: `'app:isDarkMode'`, `'app:katexFontSize'`
       - `SettingsProvider` 컴포넌트:
         - `useState`로 isDarkMode(기본 false), katexFontSize(기본 1.0) 관리
         - 초기화 `useEffect([], [])`: localStorage에서 값 읽어 state 동기화 + `document.documentElement.classList.toggle('dark', dark)` + `document.documentElement.style.setProperty('--katex-font-size', \`${fontSize}em\`)`
         - `toggleDarkMode(enabled)`: classList.toggle + localStorage 저장 + setState
         - `setKatexFontSize(size)`: style.setProperty + localStorage 저장 + setState
       - `useSettings()` 훅: `useContext(SettingsContext)` — Provider 외부 호출 시 에러

    3. `apps/web/index.html` 수정:
       - `<body>` 태그 안, `<div id="root">` 앞에 인라인 `<script>` 추가:
         ```html
         <script>
           if (localStorage.getItem('app:isDarkMode') === 'true') {
             document.documentElement.classList.add('dark')
           }
           (function() {
             var fs = localStorage.getItem('app:katexFontSize');
             if (fs) document.documentElement.style.setProperty('--katex-font-size', fs + 'em');
           })();
         </script>
         ```
       - 이 스크립트는 React 마운트 전에 동기적으로 실행되어 FOUC(flash of unstyled content) 방지

    4. `apps/web/src/index.css` 수정:
       - 파일 맨 아래에 `.katex` CSS 규칙 추가:
         ```css
         .katex {
           font-size: var(--katex-font-size, 1em) !important;
         }
         ```
       - `!important`는 KaTeX 기본 font-size를 오버라이드하기 위해 필요 (katex.min.css가 .katex에 font-size: 1.21em을 설정)
