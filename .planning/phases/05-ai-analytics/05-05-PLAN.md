**검증 항목 (순서대로):**

1. **온보딩 진단 퀴즈 (AIAN-05)**
   - 새 학생 계정으로 회원가입 + 온보딩
   - /student 접근 시 /student/onboarding-quiz로 자동 리디렉트 확인
   - 진단 퀴즈 페이지: "진단 퀴즈" 헤더 + 문제 수 안내 표시 확인
   - 5~10문제 풀기 (답 선택 + 제출)
   - 퀴즈 완료 후 /student 홈으로 자동 이동 확인
   - 이후 /student 재방문 시 더 이상 퀴즈 리디렉트 없음 확인

2. **학생 탭바 '분석' 탭**
   - 하단 탭바에 '분석' 탭(바 차트 아이콘) 표시 확인
   - '분석' 탭 클릭 → /student/analytics 이동 확인

3. **학습 분석 대시보드 (REPT-01~04)**
   - 요약 통계 카드 4종: 총 풀이 수, 정답률, 연속 학습 일수, 학습 시간 표시 확인
   - 유형별 정답률 BarChart 표시 확인 (빈 차트 없이 실데이터 표시)
   - 일별 학습 추이 LineChart 표시 확인 (14일 기간)
   - 취약 유형 RadarChart 표시 확인

4. **AI 추천 문제 (AIAN-01~04)**
   - 분석 대시보드 또는 홈에서 AI 추천 문제 목록 표시 확인
   - 풀이 30회 미만 시 "정답률 기반 추천" 배지 또는 "AI(BKT) 추천" 배지 표시 확인
   - 추천 문제 "풀기" 버튼 클릭 → 퀴즈 페이지 이동 확인

5. **일일 학습 목표 (PLAN-02)**
   - 분석 대시보드에서 "오늘의 목표" 섹션 표시 확인
   - 편집 버튼 클릭 → 목표 숫자 변경 (예: 10 → 20) → 저장
   - 목표 변경 후 진행률 바가 업데이트됨 확인

6. **스트릭 (PLAN-03)**
   - 홈 화면 "연속 학습" 카드에 실제 일수 표시 확인 (0일 이상)
   - 분석 대시보드에 스트릭 뱃지(Flame 아이콘) 표시 확인

7. **학생 홈 실데이터**
   - /student 홈 화면 4종 통계 카드(오늘 푼 문제/정답률/연속 학습/학습 시간)가 animate-pulse placeholder 없이 실데이터 표시 확인
   - "AI 추천 문제" 섹션에 실제 문제 카드 표시 확인

**에러 처리 확인:**

   - 풀이 0개 상태에서 분석 페이지: 차트가 "데이터 없음" 메시지로 graceful하게 표시됨
