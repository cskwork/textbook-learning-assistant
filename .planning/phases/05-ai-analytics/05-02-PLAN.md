**Step 3 — root package.json에 pnpm override 추가 (React 19 호환성 fix):**
현재 package.json:
```json
"pnpm": {
  "onlyBuiltDependencies": ["bcrypt"]
}
```
다음으로 수정:
```json
"pnpm": {
  "onlyBuiltDependencies": ["bcrypt"],
  "overrides": {
    "react-is": "$react-is"
  }
}
```

**Step 4 — apps/web/package.json에 react-is dependencies 추가:**
```json
"react-is": "^19.0.0"
```

**Step 5 — pnpm install 재실행:**
```bash
pnpm install
```
