**isDiagnosisCompleted 리디렉트 처리 — apps/web/src/routes/student/index.tsx:**

StudentHomePage 컴포넌트 내부에 다음 로직 추가 (useEffect + Navigate):
```typescript
import { useLiveQuery } from 'dexie-react-hooks'
import { db } from '@/lib/db'
import { Navigate } from 'react-router'

// 컴포넌트 내부
const { user } = useAuth()
const userSetting = useLiveQuery(
  () => user ? db.userSettings.where('userId').equals(user.email).first() : undefined,
  [user?.email]
)

// userSetting이 undefined이면 로딩 중 (null이면 미존재)
// userSetting === null 또는 isDiagnosisCompleted === false이면 리디렉트
if (userSetting === null || (userSetting !== undefined && !userSetting.isDiagnosisCompleted)) {
  return <Navigate to="/student/onboarding-quiz" replace />
}
```
주의: useLiveQuery는 초기에 undefined를 반환(로딩 중). undefined일 때는 로딩 스피너 표시.
null = 쿼리 완료 + 레코드 없음 = 신규 사용자.
