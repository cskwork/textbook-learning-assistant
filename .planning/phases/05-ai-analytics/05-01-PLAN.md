**apps/web/src/lib/bkt.ts** — 신규 파일:

05-RESEARCH.md의 Pattern 1 BKT 구현을 그대로 구현:
- BKTParams 인터페이스 (pInit, pTransit, pSlip, pGuess)
- DEFAULT_BKT_PARAMS (pInit: 0.1, pTransit: 0.3, pSlip: 0.1, pGuess: 0.2)
- updateBKT(pL, isCorrect, params): 단일 시도 후 P(L) 업데이트 (Bayes 업데이트 + 전이 확률)
- computeBKT(attempts, params): 시도 배열로 최종 P(L) 계산
- WEAK_THRESHOLD = 0.4 (취약 판별 기준)
- MASTERY_THRESHOLD = 0.95 (숙달 판별 기준)

연구 파일의 수식 그대로 사용:
```
posterior(correct) = pL*(1-pSlip) / (pL*(1-pSlip) + (1-pL)*pGuess)
posterior(wrong)   = pL*pSlip     / (pL*pSlip     + (1-pL)*(1-pGuess))
nextPL = posterior + (1 - posterior) * pTransit
```
