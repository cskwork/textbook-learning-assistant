- /student/workbooks — 문제집 목록 페이지 (WorkbookList)

  <how-to-verify>
**전제 조건:** 강사 계정으로 로그인하여 수학 문제 3개 이상 등록 (단원/유형/난이도 설정 포함)

**검증 항목 (순서대로):**

1. **탭바 확인 (UIUX)**
   - 학생 계정으로 로그인
   - 하단 탭바에 '문제집' 탭(책 아이콘) 확인
   - '문제집' 탭 클릭 → /student/workbooks 이동 확인

2. **문제집 목록 페이지 (WKST-03)**
   - "아직 만든 문제집이 없습니다" 안내 메시지 표시 확인
   - "새 문제집" 버튼 표시 확인

3. **문제집 생성 (WKST-01, WKST-02)**
   - "새 문제집" 버튼 클릭 → /student/workbooks/create 이동
   - 과목/단원/유형/난이도 필터 드롭다운이 표시됨
   - 문제 수 선택 (5/10/15/20/30 중 택일)
   - "문제 미리보기" 버튼 클릭 → 조건에 맞는 문제 목록 표시
   - 문제집 이름 입력 (예: "미적분 연습")
   - "저장하기" 버튼 클릭 → /student/workbooks 이동
   - 목록에 새로 만든 문제집 카드 표시 확인

4. **문제집 풀기 (WKST-03, WKST-04)**
   - 문제집 카드의 "풀기" 버튼 클릭 → /student/workbooks/:id/play 이동
   - 진행 바 (1 / N 표시) 확인
   - 첫 번째 문제 QuizPlayer 렌더링 확인
   - 답 선택/입력 후 "제출" 클릭 → 채점 결과 표시
   - "다음 문제" 버튼으로 다음 문제 이동 확인
   - 마지막 문제 완료 후 결과 요약 화면 (전체/정답/정답률) 확인

5. **학습 이력 반영 (WKST-04)**
   - 오답이 있었으면 /student/wrong-notes 에서 해당 문제 오답노트 추가 확인
   - 정답이었으면 isMastered 자동 설정 (오답노트에서 사라짐)

6. **문제집 삭제**
   - 문제집 목록에서 카드의 삭제 버튼 클릭
   - 확인 다이얼로그 → 확인 → 목록에서 제거 확인

**에러 처리 확인:**
