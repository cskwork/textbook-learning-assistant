**Confidence:** MEDIUM (WebSearch verified across 기출탭탭, 수학대왕, 콴다, 오르조, 매쓰플랫; LOW where single-source)

## Feature Landscape

### Table Stakes (사용자가 당연히 기대하는 기능)

기출문제 학습 앱에서 없으면 "이게 뭐야?" 소리 듣는 기능들.

| Feature | Why Expected | Complexity | Notes |
|---------|--------------|------------|-------|
| **단원/유형/난이도 필터 문제 풀기** | 모든 경쟁사 기본 제공; 없으면 교과서만 못함 | MEDIUM | 단원·유형·난이도 태깅 DB가 선행되어야 함 |
| **자동 채점 (객관식/단답형)** | 종이 문제집 대비 앱의 가장 기본 가치 | LOW | 정규식 + 숫자 비교로 충분; 서술형 제외 |
| **수식 정확 렌더링 (KaTeX)** | 수학 문제는 수식 없으면 읽히지 않음 | MEDIUM | LaTeX 저장 + KaTeX 렌더링; 그래프는 이미지 |
| **오답노트 / 틀린 문제 수집** | 기출탭탭·오르조 모두 핵심 기능으로 강조 | LOW | 자동 수집 + 수동 스크랩 두 방식 |
| **문제별 해설 제공** | 채점 후 해설 없으면 학습 가치 없음 | MEDIUM | 텍스트 + 이미지 혼합; 단계별 풀이가 이상적 |
| **학습 이력 / 풀이 기록 저장** | 재방문 이유 + 취약 분석의 데이터 소스 | LOW | 회원제 로그인과 세트 |
| **회원 가입 / 로그인** | 기록 동기화, 개인화의 전제 조건 | LOW | 이메일 인증으로 충분; v1은 소셜 로그인 불필요 |
| **반응형 디자인 (태블릿/모바일/PC)** | 학생은 태블릿과 폰 번갈아 사용 | MEDIUM | 기출탭탭·오르조 모두 태블릿 최적화 강조 |
| **문제 타이머** | 수능/모의고사 실전 감각 훈련 필수 | LOW | 문제별 소요 시간 기록으로 분석 소스 겸용 |
| **문제 북마크 / 스크랩** | 반복 풀기, 나중에 다시 보기 기본 UX | LOW | 오답노트와 연계 |

### Differentiators (경쟁 우위가 되는 기능)

없어도 쓰지만, 있으면 "이 앱이 맞다"고 느끼는 기능들.

| Feature | Value Proposition | Complexity | Notes |
|---------|-------------------|------------|-------|
| **AI 취약유형 분석 (BKT/DKT)** | 단순 정오답률이 아닌 지식 상태 추적; 경쟁사는 휴리스틱 기반 — 우리는 교육 AI 표준 모델 적용 | HIGH | BKT는 구현 간단, DKT(LSTM 기반)는 데이터 필요; 초기엔 BKT로 시작해 전환 권장 |
| **DIY 문제집 구성** | 학생이 "시험 범위 + 유형 + 난이도"를 조합해 나만의 문제집 생성; 기출탭탭에서 핵심 UX로 검증됨 | MEDIUM | 단원/유형/난이도/정답률 필터 조합; 서적 인쇄 없이 즉시 생성이 핵심 |
| **AI 맞춤 문제 추천** | 학습 이력 분석으로 "지금 이 문제를 풀어야 한다" 추천; 오답 패턴 기반 유사문제 서빙 | HIGH | 콜드스타트 문제는 초기 진단 테스트로 완화; BKT/DKT 결과를 추천 엔진으로 활용 |
| **취약유형 리포트 대시보드** | 학생이 "내가 어디서 틀리는지"를 시각화로 파악; 강사도 학생 현황 파악 가능 | MEDIUM | 유형별 정답률, 회차별 추이, 취약 클러스터 시각화 |
| **강사용 관리 포털** | B2B 진입점; 학원/과외 교사가 학생 관리 + 과제 출제 + 성적 분석 — 매쓰플랫이 이 시장 검증 | HIGH | 학생 그룹 관리, 커스텀 문제집 배정, 성적 리포트; 초기엔 기본 기능만 |
| **N회독 / 반복 학습 지원** | 오답을 주기적으로 다시 풀어 완전 학습 유도; 에빙하우스 망각 곡선 원리 | MEDIUM | 오답노트와 연계; 복습 주기 알림까지 가면 더 강력 |
| **문제 풀이 중 수식 노트 필기** | 태블릿 학생은 화면에 직접 풀이 메모를 적고 싶어함; 오르조가 PencilKit으로 구현 | HIGH | PWA에서는 Canvas API 또는 Fabric.js 활용; v1에서는 범위 초과 가능성 있음 |
| **PWA 오프라인 지원** | 이동 중/지하철 등 네트워크 없는 환경에서도 학습 가능; 네이티브 앱 없이 설치형 경험 | MEDIUM | Service Worker로 문제+해설 캐시; 오답 기록은 reconnect 시 sync |
| **학습 플래너 / 자동 스케줄링** | "오늘 무엇을 풀까"를 AI가 제안; 목표 시험일 역산 학습 계획 | HIGH | 기출탭탭이 제공; 복잡도 높으므로 v1.x 고려 |

### Anti-Features (요청받지만 만들지 말아야 하는 것들)

| Anti-Feature | Why Requested | Why Problematic | Alternative |
|--------------|---------------|-----------------|-------------|
| **실시간 1:1 질문 답변 (채팅)** | 콴다가 검증한 수요; 학생들이 모르는 문제 물어보고 싶어함 | 튜터 공급망 확보 + 운영 비용이 핵심 비즈니스가 됨; 교육 플랫폼이 아닌 튜터 마켓플레이스로 변질 | AI 단계별 힌트 제공 (비용 없이 스케일) |
| **게이미피케이션 과잉 (뽑기/리그/포인트샵)** | 수학대왕의 뽑기왕·매쓰킹 리그 등으로 인기; 초기 참여율 올라 보임 | 학습 동기를 외재적 보상으로 대체 → 보상 없으면 이탈; 관리 복잡도 폭증; 교육 앱 신뢰도 하락 | 학습 스트릭, 단원 완료 배지 정도로 제한 |
| **eBook / 교재 디지털화** | 기출탭탭이 비상 교재 eBook 제공; 학생들이 원함 | 저작권 확보 비용 + 법적 리스크; 문제 DB와 별개 사업 | 문제 DB 자체에 집중; 교재 연계는 v2+ |
| **소셜 피드 / 커뮤니티** | 학생들이 친구와 점수 비교, 질문 공유 원함 | 콘텐츠 모더레이션 + 커뮤니티 콜드스타트 비용이 막대함; 핵심 학습 UX와 무관 | 클래스 내 랭킹 (강사가 만든 그룹 한정) |
| **과도한 광고 노출** | 무료 앱 수익화 수단; 콴다가 사용 | 콴다 앱스토어 리뷰에서 "게임 광고로 공부 흐름 끊김" 가장 많은 불만 | v1 광고 없음, v2에서 프리미엄 구독으로 수익화 |
| **서술형 문제 AI 채점** | 서술형 풀이까지 확인하고 싶어함 | GPT 기반 채점의 정확도 불안정; 교육 평가에서 오채점 리스크 큼 | 객관식+단답형으로 범위 제한; 서술형은 강사 수동 검토 |
| **실시간 수능 모의고사 (동시접속 시험)** | 오프라인 모의고사 대체 수요 있음 | WebSocket 동시접속 인프라 + 부정행위 방지 + 채점 동시성 처리가 완전 다른 제품 | 시간제한 모드로 자가 시험 체험으로 충분 |

## Feature Dependencies

```
[문제 DB (단원/유형/난이도 태깅)]
    └──requires──> [문제 풀이 엔진]
                       └──requires──> [자동 채점]
                       └──requires──> [KaTeX 수식 렌더링]
                       └──requires──> [문제별 해설]

[회원 인증 / 로그인]
    └──requires──> [학습 이력 저장]
                       └──requires──> [오답노트]
                       └──requires──> [AI 취약유형 분석 (BKT/DKT)]
                                          └──requires──> [AI 맞춤 문제 추천]
                                          └──requires──> [취약유형 리포트]

[DIY 문제집]
    └──requires──> [문제 DB 필터링]
    └──requires──> [문제 풀이 엔진]

[강사 관리 포털]
    └──requires──> [회원 인증 (역할 기반)]
    └──requires──> [학습 이력 / 리포트]
    └──requires──> [DIY 문제집 (과제 출제용)]

[PWA 오프라인]
    └──requires──> [Service Worker 캐시 전략]
    └──enhances──> [문제 풀이 엔진]

[N회독 반복 학습]
    └──requires──> [오답노트]
    └──enhances──> [AI 맞춤 문제 추천]

[학습 플래너]
    └──requires──> [학습 이력]
    └──requires──> [AI 취약유형 분석]
    └──enhances──> [AI 맞춤 문제 추천]
```

### Dependency Notes

- **AI 취약유형 분석은 학습 이력에 의존한다:** 최소 20-30회 이상의 풀이 데이터 없이는 BKT/DKT 모델이 의미 있는 결과를 내지 못함. 초기 사용자에게는 단원별 정답률 기반 휴리스틱 분석을 fallback으로 제공해야 함.
- **강사 포털은 학생 기능이 먼저 완성되어야 한다:** 강사는 학생 데이터를 소비하는 역할. 학생 풀이/이력/리포트가 없으면 강사 포털은 빈 껍데기.
- **DIY 문제집은 문제 DB 품질에 직결된다:** 단원/유형 태깅이 부실하면 필터가 의미 없음. 문제 DB 구축이 핵심 전제 조건.
- **PWA 오프라인과 AI 추천은 충돌한다:** AI 추천은 서버 사이드 연산이지만 오프라인 학습은 클라이언트 사이드만 동작함. 오프라인에서는 "마지막 추천 목록"을 캐시해서 제공하는 방식으로 타협.

## MVP Definition

### Launch With (v1 — 핵심 가치 검증)

- [x] **문제 풀이 엔진 (객관식+단답형+KaTeX)** — 수학 앱의 존재 이유
- [x] **자동 채점** — 종이 문제집 대비 유일한 이점
- [x] **단원/유형/난이도 필터** — 목표 학습의 기반
- [x] **오답노트 자동 수집** — 재방문 유인, 구현 복잡도 낮음
- [x] **문제별 해설** — 채점 후 학습 완결
- [x] **DIY 문제집** — 핵심 차별점, 기출탭탭에서 검증된 UX
- [x] **AI 취약유형 분석 (BKT)** — 핵심 차별점; DKT는 v1.x
- [x] **취약유형 리포트 대시보드** — AI 분석의 아웃풋
- [x] **회원 인증 (이메일)** — 이력 저장의 전제
- [x] **강사용 기본 관리** — 학생 그룹 + 과제 출제 최소 기능
- [x] **반응형 (태블릿/모바일/PC)** — 학생 사용 환경
- [x] **PWA 설치 + 오프라인 기본** — 앱스토어 없이 설치 경험

### Add After Validation (v1.x)

- [ ] **N회독 반복 학습 스케줄링** — 오답노트 쌓이고 나서 의미 있음
- [ ] **DKT 모델 전환** — 사용자 데이터 충분히 쌓인 후 (최소 1,000+ 학생)
- [ ] **AI 맞춤 문제 추천 고도화** — BKT 결과 기반 추천 로직 개선
- [ ] **학습 플래너 / 자동 스케줄링** — 이력 데이터 있을 때 효과적
- [ ] **강사 포털 고도화** — 초기 강사 피드백 반영

### Future Consideration (v2+)

- [ ] **문제 필기 노트 (Canvas 기반)** — 구현 복잡도 높음; PWA에서 PencilKit 미지원
- [ ] **결제 / 프리미엄 구독** — v1 무료로 사용자 확보 후
- [ ] **DKT 모델 + 개인화 알고리즘 고도화** — 데이터 규모 확보 후
- [ ] **eBook 교재** — 저작권 계약 필요
- [ ] **수학 외 과목 확장** — 수학 검증 후 확장
