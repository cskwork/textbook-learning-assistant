  <name>Task 1: Button + Badge 컴포넌트 기출탭탭 스타일 리뉴얼</name>
  <files>apps/web/src/components/ui/button.tsx, apps/web/src/components/ui/badge.tsx, apps/web/src/index.css</files>
  <action>
1. **Button 컴포넌트 (button.tsx)** buttonVariants 수정:
   - 기본 클래스에 `rounded-xl` (기존 rounded-md에서 변경) 추가
   - 기본 클래스에 `shadow-sm` 추가 (기본 미니멀 그림자)
   - 기본 클래스에 `cursor-pointer` 추가
   - transition을 `transition-all duration-200` 으로 변경 (hover 효과 부드럽게)
   - variant별 조정:
     - `default`: `bg-primary text-primary-foreground shadow-md hover:bg-primary/90 hover:shadow-lg hover:-translate-y-0.5 active:translate-y-0 active:shadow-sm` — hover 시 리프트 + 그림자 확대, 클릭 시 원래 위치
     - `destructive`: 기존 유지 + `hover:-translate-y-0.5 active:translate-y-0` 추가
     - `outline`: `rounded-xl border-2` (테두리 두께 증가) + `hover:shadow-sm hover:-translate-y-0.5`
     - `secondary`: 기존 유지 + `shadow-xs hover:shadow-sm`
     - `ghost`: 기존 유지 (hover lift 없음, ghost는 플랫)
     - `link`: 기존 유지
   - size 조정:
     - `default`: `h-10 px-5 py-2.5` (살짝 높이 증가, 패딩 여유)
     - `sm`: `h-8 px-3.5` (기존과 유사)
     - `lg`: `h-11 px-7 text-base` (크게)
     - `xs`, `icon`, `icon-xs`, `icon-sm`, `icon-lg`: 기존 유지하되 rounded-xl 적용

2. **Badge 컴포넌트 (badge.tsx)** badgeVariants에 교육 앱용 variant 추가:
   - 기존 variant 유지
   - `success` 추가: `bg-success/15 text-success border-success/25` (초록 계열)
   - `warning` 추가: `bg-warning/15 text-warning border-warning/25` (호박 계열)
   - `info` 추가: `bg-info/15 text-info border-info/25` (하늘 계열)

   주의: success/warning/info는 10-01에서 추가한 CSS 변수(--success, --warning, --info)를 참조한다. Tailwind v4에서 이 변수가 @theme inline에 --color-success 등으로 매핑되어 있어야 `bg-success` 등이 작동한다.

3. **index.css에 컴포넌트 보조 유틸리티 추가:**
   ```css
   /* 컴포넌트 보조 유틸리티 */
   .btn-press {
     transition: transform 0.1s ease;
   }
   .btn-press:active {
     transform: scale(0.97);
   }
   ```
