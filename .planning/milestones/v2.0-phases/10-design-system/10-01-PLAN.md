<task type="auto">
  <name>Task 1: Pretendard 폰트 CDN 로딩 + 타이포그래피 시스템</name>
  <files>apps/web/index.html, apps/web/src/index.css</files>
  <action>
1. index.html `<head>`에 Pretendard 폰트 CDN 링크 추가:
   ```html
   <link rel="stylesheet" as="style" crossorigin href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css" />
   ```
   - preconnect 힌트도 추가: `<link rel="preconnect" href="https://cdn.jsdelivr.net" crossorigin />`

2. index.css에서 body의 font-family를 Pretendard 우선으로 변경:
   ```css
   body {
     font-family: 'Pretendard Variable', Pretendard, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Noto Sans KR', sans-serif;
   }
   ```

3. index.css @layer base 안에 타이포그래피 유틸리티 클래스 추가 (Tailwind v4 CSS 변수 방식):
   - 교육 앱 가독성을 위해 본문 기본 줄간격을 1.6 ~ 1.7로 설정
   - heading 요소(h1-h4)에 font-weight: 700, letter-spacing: -0.02em 적용
   - 기본 paragraph에 line-height: 1.65 적용
   - small/caption 텍스트에 text-muted-foreground 색상 적용

4. @theme 블록에 교육 앱 최적화 커스텀 spacing 추가 (있으면 유지, 없으면 추가):
   - `--spacing-page: 1.25rem` (모바일 페이지 좌우 패딩)
   - `--spacing-page-lg: 2rem` (태블릿 이상 페이지 좌우 패딩)

주의: @theme inline 블록(shadcn 변수 매핑)은 절대 삭제하지 않는다. 기존 @theme 블록의 breakpoint 변수도 유지한다.
  </action>
  <verify>
- `pnpm --filter web build` 성공 (TypeScript + Vite 빌드 에러 없음)
- index.html에 pretendard CDN 링크 존재 확인
- index.css body font-family에 'Pretendard Variable' 포함 확인
  </verify>
