- transition: duration 1.2초, easeOut
- 스타일: text-yellow-400 font-bold text-2xl, pointer-events-none, z-50
- "+{amount} XP" 텍스트 표시
- onAnimationComplete에서 onComplete 콜백 호출

**ComboCounter.tsx:**
- props: `comboCount` (현재 콤보 수), `multiplier` (현재 배수)
- 화면 중앙에 크고 강렬하게 — 격투 게임 콤보 느낌 (유저 요청)
- comboCount >= 2일 때만 표시
- AnimatePresence + motion.div: initial={{ scale:0, opacity:0 }} → animate={{ scale:1, opacity:1 }} → exit={{ scale:0, opacity:0 }}
- transition: type 'spring', damping 8, stiffness 200 (탄성감)
- "{comboCount}x 콤보!" 텍스트 — text-4xl~5xl font-black

- key={comboCount}로 매 콤보마다 새 애니메이션 트리거
