**badge-definitions.ts:**
- `BadgeDefinition` 인터페이스: id, name, description, category('study'|'streak'|'achievement'), rarity('common'|'rare'|'epic'), icon(이모지), checkCondition 함수
- `BadgeCheckContext` 인터페이스: totalXP, level, streakDays, totalCorrect, comboMax
- `BADGE_DEFINITIONS` 배열 (15~18개):
  - 학습 카테고리: first_correct(1문제), study_10, study_50, study_100(rare), study_500(epic)
  - 연속 카테고리: streak_3, streak_7(rare), streak_30(epic), combo_3, combo_5(rare)
  - 성취 카테고리: level_5, level_10(rare), level_20(epic), level_50(epic)
  - 첫날 2-3개 획득 가능하도록 first_correct + study_10은 common으로 낮은 기준
- `checkCondition`은 순수 함수: `ctx => ctx.totalCorrect >= 1` 패턴

**gamification.service.ts:**
- `AwardXPResult` 인터페이스: xpAwarded, totalXP, previousLevel, newLevel, leveledUp, unlockedBadges(string[])
- `awardXP(studentId, baseXP, reason, comboMultiplier)`:
  - 반드시 `db.transaction('rw', [db.gamificationProfiles, db.xpEvents, db.badges], async () => {...})` 내부에서 실행 (Pitfall 1 방지)
  - 프로필 없으면 생성, XP 이벤트 기록, 프로필 totalXP/level 업데이트, 뱃지 체크
  - `calculateLevel()` import from xp-formula.ts
- `updateStreak(studentId)`:
  - `new Date().toDateString()` 로컬 타임존 비교 (Pitfall 4 방지 — UTC 아님)
  - 어제=스트릭 증가, 오늘 이미 학습=유지, 그 외=리셋(1)
  - 스트릭 보너스: 3일=50XP, 7일=150XP, 14일=300XP, 30일=500XP
- `checkAndAwardBadges(studentId, totalXP, level, streakDays)`:
  - xpEvents에서 totalCorrect 집계 (`reason: 'quiz_correct'` 카운트)
  - BADGE_DEFINITIONS 순회, checkCondition 통과 && DB에 미등록 → badges 테이블에 추가
  - 새로 획득한 뱃지 ID 배열 반환

**challenge.service.ts:**
- `getDailyChallengeConfig(date)`: 주말=5문제 난이도3, 평일=3문제 요일별 난이도
- `getDailyChallengeQuestions(date)`: 날짜 시드 기반 pseudorandom shuffle → 문제 선택. `db.questions.toArray()` 후 시드 셔플.
- `isDailyChallengeCompleted(studentId, date)`: xpEvents에서 당일 'daily_challenge' reason 존재 여부 (Pitfall 5 방지)
- `getWeeklyChallengeProgress(studentId)`: 이번 주 월요일 00:00~현재 사이 'quiz_correct' xpEvents 집계. 목표 50문제. 완료 여부 = xpEvents에 'weekly_challenge' reason 존재 체크.
- `seededShuffle(array, seed)`: 시드 기반 Fisher-Yates 셔플 (간단한 LCG 난수 생성기)

**useGamification.ts:**
- `useLiveQuery`로 `db.gamificationProfiles.where('studentId').equals(studentId).first()` 구독 — dependency [studentId] (Pitfall 2 방지)
- `useLiveQuery`로 `db.badges.where('studentId').equals(studentId).toArray()` 구독
- 반환: profile, xpForNextLevel, xpProgress(0~1), allBadges, isLoading

**useCombo.ts:**
- `useState(0)` 콤보 카운터 (세션 메모리 only, DB 저장 안 함)
- `onCorrect()`: 카운터 증가, 현재 콤보의 multiplier 반환 (클로저 주의: prev+1로 계산)
- `onWrong()`: 카운터 리셋 0
- 반환: comboCount, multiplier, onCorrect, onWrong, resetCombo
