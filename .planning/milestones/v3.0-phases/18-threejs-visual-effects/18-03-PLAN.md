1. **LevelUpVfx.tsx** 생성 (`apps/web/src/components/game/effects/LevelUpVfx.tsx`):
   - **독립 R3F Canvas 사용** — LevelUpOverlay는 fixed inset-0 z-[100] 오버레이이므로, 배경 Canvas와 별도로 동작
   - Props: `{ visible: boolean }`
   - visible=true 시 Canvas 마운트, false 시 언마운트 (WebGL 컨텍스트 해제)

2. **Canvas 설정:**
   ```tsx
   <Canvas
     dpr={[0.5, 1]}
     gl={{ antialias: false, alpha: true }}
     camera={{ position: [0, 0, 10], fov: 50 }}
     style={{ position: 'absolute', inset: 0, zIndex: -1 }}
   >
     <RingExpand />
     <LevelSparkles />
   </Canvas>
   ```

3. **RingExpand 컴포넌트:**
   - TorusGeometry(0.1, 0.02, 8, 64) — 얇은 링
   - useFrame에서 ring scale 0 → 15 (약 1초간 확장), opacity 1 → 0
   - 골드색 meshBasicMaterial: `color="#fbbf24" transparent opacity`
   - 확장 완료 후 scale 리셋 (visible이 false→true로 다시 바뀔 때 재트리거)
   - 링 2개 — 0.2초 딜레이로 두 번째 링 시작 (시간차 확장 효과)

4. **LevelSparkles 컴포넌트:**
   - drei `<Sparkles>` 사용: `count={80} scale={[15, 15, 5]} size={3} speed={2} color="#fbbf24" opacity={0.8}`
   - 또는 InstancedMesh로 커스텀 sparkle (작은 빛나는 점이 중앙에서 바깥으로 퍼지는 느낌)
   - 레벨업 느낌의 밝은 골드/화이트 파티클

5. **LevelUpOverlay.tsx 수정:**
   - React.lazy로 LevelUpVfx import:
     ```tsx
     const LevelUpVfx = lazy(() => import('@/components/game/effects/LevelUpVfx'))
     ```
   - useFunMode() 훅으로 isFunMode 체크
   - visible && isFunMode 일 때만 LevelUpVfx 렌더링 (일반 모드에서는 기존 CSS 연출만)
   - LevelUpVfx를 기존 배경 div와 방사형 빛 효과 사이에 배치:
     ```tsx
     {/* 배경: 블랙 반투명 */}
     <div className="absolute inset-0 bg-black/80" />

     {/* Three.js 파티클 배경 — FunMode only */}
     {isFunMode && (
       <Suspense fallback={null}>
         <LevelUpVfx visible={visible} />
       </Suspense>
     )}

     {/* 방사형 빛 효과 (기존) */}
     ```
   - **주의:** 기존 Framer Motion 애니메이션, 타이머, 클릭 닫기 로직 모두 보존
   - **주의:** LevelUpVfx Canvas가 2.5초 타이머 내에서만 존재 (visible=false 시 언마운트되면 WebGL 컨텍스트 해제)
  </action>

1. **StreakFlame.tsx** 생성 (`apps/web/src/components/game/effects/StreakFlame.tsx`):
   - **CSS + Framer Motion 기반** (Three.js 불필요 — 작은 UI 요소이므로 CSS가 효율적)
   - Props: `{ streakDays: number; className?: string }`
   - streakDays 기반 인텐시티 레벨:
     - 0~2일: 없음 (렌더링 안 함)
     - 3~6일: 약한 불꽃 (작은 크기, opacity 0.6)
     - 7~13일: 중간 불꽃 (보통 크기, opacity 0.8, 약간의 glow)
     - 14~29일: 강한 불꽃 (큰 크기, opacity 1.0, 강한 glow)
     - 30일+: 최강 불꽃 (큰 크기 + 파란 불꽃 추가, glow 극대)

2. **불꽃 시각 효과 구현:**
   - CSS gradient + @keyframes로 불꽃 모양:
     - radial-gradient 오렌지→노란색 불꽃 형태
     - animation: flame-flicker (scale + opacity + translateY 미세 변화, 0.5초 주기)
     - 여러 레이어(2~3) 겹쳐서 깊이감
   - 또는 Framer Motion으로:
     - animate={{ y: [0, -3, 0], scale: [1, 1.05, 1], opacity: [0.8, 1, 0.8] }}
     - transition={{ repeat: Infinity, duration: 0.8 }}
   - 불꽃 색상:
     - 일반: 오렌지/노란색 (#f97316, #fbbf24)
     - 30일+: 파란/보라 추가 (#60a5fa, #8b5cf6) — "신비로운 불꽃" 느낌
   - box-shadow glow 효과: `0 0 ${glowSize}px ${glowColor}`

3. **홈 화면 연동** (`apps/web/src/routes/student/index.tsx`):
   - useFunMode() 체크
   - StreakCounter 컴포넌트 옆(또는 뒤)에 StreakFlame 렌더링
   - streakDays 값은 기존 StreakCounter에서 사용하는 것과 동일한 소스 (useGamification 훅 또는 streak service)
   - isFunMode일 때만 StreakFlame 표시
   - 레이아웃: StreakCounter를 relative 컨테이너로 감싸고, StreakFlame을 absolute 위치로 StreakCounter 아이콘 뒤에 배치
