2. **useGpuTier.ts** 생성 (`apps/web/src/components/game/vfx/useGpuTier.ts`):
   - `VfxQuality` 타입 export: `'high' | 'medium' | 'low' | 'css-only'`
   - `useGpuTier()` 훅: 내부적으로 WebGL context 생성 시도로 지원 여부 체크
   - WebGL 미지원 → 'css-only' 반환
   - **주의:** `useDetectGPU()`는 Canvas 내부에서만 사용 가능. useGpuTier은 Canvas 외부에서 호출되므로 간단한 WebGL feature detection + navigator.hardwareConcurrency + isMobile 체크로 구현
   - isMobile 감지: `navigator.maxTouchPoints > 0 && window.innerWidth < 1024`
   - 모바일이면 'low', WebGL2 미지원이면 'css-only', 그 외 'high'

3. **CssFallbackBg.tsx** 생성 (`apps/web/src/components/game/vfx/CssFallbackBg.tsx`):
   - WebGL 미지원 시 화면별 CSS gradient 배경 컴포넌트
   - scene prop에 따라 다른 gradient 적용:
     - 'space': 짙은 남색→검정 radial gradient + 미세 별 도트 (CSS repeating-radial-gradient)
     - 'neon': 사이버펑크 보라→검정 gradient
     - 'wave': 파랑→청록 gradient
     - 'mountain': 녹색→갈색 gradient
   - `fixed inset-0 -z-10 pointer-events-none` 레이아웃
   - 미세한 CSS animation (gradient-shift @keyframes)으로 ambient 느낌

4. **ThreeBackground.tsx** 생성 (`apps/web/src/components/game/ThreeBackground.tsx`):
   - `default export` (React.lazy 호환)
   - Props: `{ scene: 'space' | 'neon' | 'wave' | 'mountain' }`
   - 내부적으로 useGpuTier() 호출 — 'css-only'이면 CssFallbackBg 렌더링
   - WebGL 지원 시:
     - `<Canvas>` 감싸기: `dpr={quality === 'low' ? [0.5, 1] : [1, 1.5]}`, `gl={{ antialias: false, alpha: true, powerPreference: 'low-power' }}`, `camera={{ position: [0, 0, 5], fov: 60 }}`, `frameloop="always"`
     - `<PerformanceMonitor>` 추가: `onDecline={() => setDpr(0.5)}`, `onIncline(() => setDpr(1.5))`, `flipflops={3}`, `onFallback={() => setDpr(0.5)}`
     - SceneRouter 컴포넌트: scene prop에 따라 SpaceBg/NeonGridBg/WaveBg/MountainBg 중 하나 렌더링
   - 레이아웃: `<div className="fixed inset-0 -z-10 pointer-events-none">` 래퍼
   - React.Suspense로 내부 배경 컴포넌트 감싸기 (로딩 중 빈 화면 대신 CSS fallback)

5. **FunModeGate.tsx 수정** (`apps/web/src/components/game/FunModeGate.tsx`):
   - Phase 15에서 주석 처리된 ThreeBackground lazy import 주석 해제:
     ```tsx
     const ThreeBackground = lazy(() => import('@/components/game/ThreeBackground'))
     ```
   - Props에 `scene?: string` 추가
   - scene이 제공되고 isFunMode일 때만 ThreeBackground 렌더링
   - useFunMode() 훅으로 isFunMode 체크

1. **SpaceBg.tsx** (홈 — 우주/별 테마):
   - drei `<Stars>` 컴포넌트 사용: `radius={80} depth={60} count={3000} factor={4} saturation={0.2} fade speed={0.5}`
   - useFrame으로 느린 회전: `rotation.y += delta * 0.02`, `rotation.x += delta * 0.01`
   - 마우스 parallax: `useThree(state => state.pointer)`로 마우스 위치 → starsRef.rotation.z = pointer.x * 0.05
   - **주의:** `const tempVec = useMemo(() => new THREE.Vector3(), [])` — useFrame 내 new 금지
   - 가끔 유성: 추가 mesh (작은 sphere)가 대각선으로 빠르게 이동 (주기적으로, ~10초 간격)
     - useRef로 유성 활성 상태 관리, useFrame에서 위치 업데이트
     - 모바일(quality === 'low')이면 유성 비활성화

2. **NeonGridBg.tsx** (퀴즈 — 네온 격자/사이버펑크):
   - Tron 스타일 와이어프레임 바닥이 앞으로 스크롤되는 느낌
   - `<gridHelper args={[100, 50, '#8b5cf6', '#6366f1']} />` 사용 or 커스텀 PlaneGeometry + wireframe
   - useFrame에서 grid position.z를 매 프레임 앞으로 이동, 임계값 도달 시 리셋 (무한 스크롤 효과)
   - 마우스 parallax: 카메라 rotation 미세 변화 (pointer.x/y * 0.03)
   - 상단에 작은 빛나는 파티클 몇 개 (drei `<Sparkles count={30} scale={[20, 10, 20]} color="#a78bfa" />`)
   - 전체적으로 보라/남색 분위기

3. **WaveBg.tsx** (분석 — 파도/물결):
   - PlaneGeometry(200, 200, 64, 64) + meshBasicMaterial wireframe 또는 커스텀 shader
   - useFrame에서 vertices를 sin/cos wave로 변형: `position.z = Math.sin(x * 0.1 + time) * Math.cos(y * 0.1 + time) * 2`
   - 카메라 약간 위에서 아래를 내려다보는 각도 (position: [0, 8, 8], lookAt: [0, 0, 0])
   - 파란색/청록색 팔레트 (color="#38bdf8")
   - 마우스 parallax: 카메라 position 미세 이동

4. **MountainBg.tsx** (프로필 — 산/자연):
   - 여러 겹의 삼각형 산 모양 (ConeGeometry 또는 커스텀 뾰족한 지형)
   - 뒤쪽에 큰 산, 앞쪽에 작은 산 (3-4 레이어, 각기 다른 y 높이와 색상)
   - 색상: 짙은 녹색 → 밝은 녹색 (뒤 → 앞)
   - 느린 좌우 oscillation: useFrame에서 group rotation.y += sin(time * 0.3) * 0.001
   - 마우스 parallax: 각 산 레이어가 다른 속도로 반응 (뒤 레이어 느리게, 앞 레이어 빠르게)
   - 모바일: 산 레이어 2개로 감소
