   - useVfxEvents()의 trigger.current 변화 감지 (useFrame 내부)
   - trigger.type === 'correct' 또는 'combo' 시:
     - comboStep = (trigger.data as any)?.comboStep ?? 1
     - activeCount = Math.min(MAX_PARTICLES, 30 + comboStep * 20) — 콤보 단계에 따라 파티클 수 증가
     - 각 활성 파티클: velocity 랜덤 방사형 (0,0,0 중심, 반경 3~6), maxLife 0.8~1.2초
     - trigger.current = null (소비 완료)

4. **useFrame 파티클 업데이트:**
   - 활성 파티클만 순회 (p.active && p.life < p.maxLife)
   - position = velocity * life (방사형 확산)
   - scale = (1 - life/maxLife) * 0.08 * comboScale — 점점 작아짐
   - 중력 효과: y -= 4.9 * life^2
   - life += delta
   - tempObj.updateMatrix() → instancedMesh.setMatrixAt(i, tempObj.matrix)
   - instancedMesh.instanceMatrix.needsUpdate = true

5. **색상 — 콤보 단계별:**
