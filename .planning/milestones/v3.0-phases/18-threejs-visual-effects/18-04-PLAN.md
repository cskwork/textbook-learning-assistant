   - canvas-confetti 라이브러리 사용 (R3F Canvas와 완전 독립)
   - Props: `{ fire: boolean }`
   - useRef로 canvas 엘리먼트 + confetti 인스턴스 관리

2. **초기화:**
   ```tsx
   const canvasRef = useRef<HTMLCanvasElement>(null)
   const confettiRef = useRef<confetti.CreateTypes | null>(null)

   useEffect(() => {
     if (canvasRef.current) {
       confettiRef.current = confetti.create(canvasRef.current, {
         resize: true,
         useWorker: true, // 별도 worker에서 파티클 계산 → 메인 스레드 블록 없음
       })
     }
     return () => { confettiRef.current?.reset() }
   }, [])
   ```

3. **fire 트리거:**
   ```tsx
   useEffect(() => {
     if (fire && confettiRef.current) {
       // 중앙에서 폭발
       confettiRef.current({
         particleCount: 100,
         spread: 160,
         origin: { y: 0.6 },
         colors: ['#fbbf24', '#34d399', '#60a5fa', '#f472b6', '#a78bfa'],
       })
       // 0.2초 후 양쪽에서 추가 폭발
       setTimeout(() => {
         confettiRef.current?.({
           particleCount: 50,
           angle: 60,
           spread: 55,
           origin: { x: 0 },
           colors: ['#fbbf24', '#34d399'],
         })
         confettiRef.current?.({
           particleCount: 50,
           angle: 120,
           spread: 55,
           origin: { x: 1 },
           colors: ['#60a5fa', '#f472b6'],
         })
       }, 200)
     }
   }, [fire])
   ```

4. **렌더링:**
   ```tsx
   return <canvas ref={canvasRef} className="fixed inset-0 z-50 pointer-events-none" />
   ```
   - z-50: React DOM 위, 모달 아래 (LevelUpOverlay z-[100] 아래)
   - pointer-events-none: 클릭 패스스루

5. **퀴즈 페이지 연동** (`apps/web/src/routes/student/quiz/index.tsx`):
