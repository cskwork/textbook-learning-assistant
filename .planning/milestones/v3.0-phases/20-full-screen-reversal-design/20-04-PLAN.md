## 1. FunModeAnalytics 분석 화면 (SCRN-03)

`apps/web/src/components/analytics/FunModeAnalytics.tsx` 생성:
- 기존 분석 대시보드 데이터/로직 재사용 + 비주얼 오버라이드
- **RPG 스탯 화면 스타일:**
  - 배경: var(--fun-bg-primary)
  - 차트 컨테이너: GlassCard 래핑
  - 차트 색상 오버라이드: 네온 라인(cyan/magenta/gold)
  - 기존 라인 차트 → 네온 글로우 stroke 스타일
  - 기존 바 차트 → 네온 그라데이션 fill
  - 기존 레이더 차트 → StatHexagon 스타일 오버레이 (가능하면 재사용)
- **능력치 요약 카드:** 정확도/속도/학습량 → 각각 ShieldIcon/LightningIcon/SwordIcon + NeonText
- **취약 유형 표시:** 기존 취약 유형 카드 → 어둡고 위협적인 "위험 지역" 카드 스타일
- **학습 트렌드 그래프:** 네온 라인 + 다크 그리드 배경
- 반응형: 태블릿 2열 그리드, 모바일 1열

`apps/web/src/routes/student/analytics/index.tsx` 수정:
- useFunMode() → isFunMode
- isFunMode === true → `<FunModeAnalytics />` (React.lazy)
- isFunMode === false → 기존 분석 화면 유지

## 1. 모드 복원 검증 체크리스트

모든 주요 화면에서 반전 모드 OFF 시 기존 디자인으로 즉시 복원되는지 검증:

1. **홈 화면** (/student): FunModeHome → 기존 홈 즉시 전환
2. **퀴즈 화면** (/student/quiz): GameQuizHud 해제 → 기존 퀴즈 UI
3. **분석 화면** (/student/analytics): FunModeAnalytics → 기존 분석
4. **오답노트** (/student/wrong-notes): MonsterCodex → 기존 오답노트
5. **문제집** (/student/workbooks): FunModeWorkbooks → 기존 문제집
6. **강사 포털** (/instructor/*): 다크 테마 해제 → 기존 밝은 테마
7. **마이페이지** (/student/profile): CharacterProfile → 기존 프로필

각 화면에서:
- `useFunMode()` 분기가 올바르게 동작하는지
- CSS 변수가 [data-fun-mode='true'] 스코프 내부에만 존재하는지
- 반전 모드 전용 컴포넌트가 일반 모드에서 import되지 않는지 (lazy loading)
- React.lazy + Suspense가 정상 동작하는지
