## SVG 커스텀 아이콘 12종 생성

`apps/web/src/components/game/icons/` 디렉토리에 게임 테마 전용 SVG 아이콘 컴포넌트 12종 생성.

**각 아이콘 컴포넌트 인터페이스:**
```tsx
interface GameIconProps {
  size?: number;       // default 24
  color?: string;      // default 'currentColor'
  className?: string;
  glow?: boolean;      // default false — 네온 글로우 필터 적용 여부
}
```

**아이콘 목록 (모두 SVG path 직접 작성, 이모지 절대 금지):**
1. SwordIcon — 검 (공격/퀴즈 도전)
2. ShieldIcon — 방패 (방어/오답 방지)
3. HeartIcon — 하트 (HP/체력)
4. StarIcon — 별 (XP/보상)
5. MonsterIcon — 몬스터 실루엣 (오답노트 몬스터 도감)
6. TrophyIcon — 트로피 (리더보드/업적)
7. FlameIcon — 불꽃 (스트릭/콤보)
8. CrownIcon — 왕관 (레벨/랭킹 1위)
9. ScrollIcon — 두루마리 (문제집/퀘스트)
10. SkullIcon — 해골 (보스배틀/서바이벌)
11. LightningIcon — 번개 (타임어택/스피드)
12. GemIcon — 보석 (희귀 뱃지/보너스)

**SVG 디자인 가이드라인:**
- viewBox="0 0 24 24" 통일
- stroke 기반 라인아트 스타일 (fill="none", strokeWidth={1.5})
- glow={true}일 때 SVG filter로 drop-shadow 네온 글로우 적용
- 색상은 color prop으로 제어, 기본 currentColor

**barrel export:** `apps/web/src/components/game/icons/index.ts`

## CSS 변수 확장 ([data-fun-mode='true'])

`apps/web/src/index.css`의 기존 `[data-fun-mode='true']` 블록을 확장.

**추가할 CSS 변수:**
```css
[data-fun-mode='true'] {
  /* 다크 배경 팔레트 */
  --fun-bg-primary: #0a0a1a;
  --fun-bg-secondary: #111128;
  --fun-bg-tertiary: #1a1a2e;
  --fun-bg-card: rgba(255, 255, 255, 0.05);
  --fun-bg-card-hover: rgba(255, 255, 255, 0.08);

  /* 네온 악센트 */
  --fun-neon-cyan: #00d4ff;
  --fun-neon-magenta: #ff00ff;
  --fun-neon-gold: #ffd700;
  --fun-neon-green: #00ff88;
  --fun-neon-red: #ff3366;

  /* 텍스트 (밝은 글자 — 가독성 최우선) */
  --fun-text-primary: #f0f0ff;
  --fun-text-secondary: #a0a0c0;
  --fun-text-accent: var(--fun-neon-cyan);
  --fun-text-muted: #606080;

  /* 글래스모피즘 */
  --fun-glass-bg: rgba(255, 255, 255, 0.05);
  --fun-glass-border: rgba(255, 255, 255, 0.1);
  --fun-glass-blur: 12px;

  /* 네온 글로우 */
  --fun-glow-cyan: 0 0 10px rgba(0, 212, 255, 0.5), 0 0 20px rgba(0, 212, 255, 0.2);
  --fun-glow-magenta: 0 0 10px rgba(255, 0, 255, 0.5), 0 0 20px rgba(255, 0, 255, 0.2);
  --fun-glow-gold: 0 0 10px rgba(255, 215, 0, 0.5), 0 0 20px rgba(255, 215, 0, 0.2);

  /* 보더 그라데이션 */
  --fun-border-gradient: linear-gradient(135deg, var(--fun-neon-cyan), var(--fun-neon-magenta));

  /* 전환 */
  --fun-transition-theme: background-color 0.3s ease, color 0.3s ease, border-color 0.3s ease;
}
```

**주의:** 기존 `[data-fun-mode='true']` 변수를 덮어쓰지 말고, 기존 변수 아래에 추가. 기존 변수와 충돌하는 이름이 있으면 기존 값을 새 다크 팔레트 값으로 업데이트.

## 공용 UI 컴포넌트 4종 생성

`apps/web/src/components/game/ui/` 디렉토리에 게임 테마 전용 빌딩블록 컴포넌트 생성.

### 1. GlassCard.tsx
```
반투명 글래스모피즘 카드 컴포넌트
- background: var(--fun-glass-bg)
- backdrop-filter: blur(var(--fun-glass-blur))
- border: 1px solid var(--fun-glass-border)
- border-radius: 12px
- hover 시 background: var(--fun-bg-card-hover) + 미세 scale(1.01)
- children, className, onClick prop
- Framer Motion layoutId 지원 (optional prop)
```

### 2. NeonBorder.tsx
```
네온 글로우 보더 래퍼 컴포넌트
- CSS gradient border 기법: padding 1px + background var(--fun-border-gradient)
- 내부 children에 다크 배경 적용
- box-shadow: var(--fun-glow-cyan) (기본) — color prop으로 cyan/magenta/gold 선택
- @keyframes border-glow: opacity 0.6~1.0 pulse 애니메이션
- animated prop (default true) — false면 정적 보더
```

### 3. NeonText.tsx
```
네온 글로우 텍스트 컴포넌트
- text-shadow 기반 네온 글로우 효과
- color prop: 'cyan' | 'magenta' | 'gold' | 'green' | 'red' (default 'cyan')
- as prop: 'h1' | 'h2' | 'h3' | 'p' | 'span' (default 'span')
- glow intensity prop: 'low' | 'medium' | 'high' (default 'medium')
  - low: text-shadow 1단계 (10px blur)
  - medium: text-shadow 2단계 (10px + 20px blur)
  - high: text-shadow 3단계 (10px + 20px + 40px blur)
- children, className prop
```

### 4. LaserButton.tsx
```
레이저 라인 강조 버튼 컴포넌트
- 기본 상태: var(--fun-glass-bg) 배경 + var(--fun-glass-border) 보더
- hover: 네온 보더 라인이 좌→우로 스캔하는 @keyframes laser-scan 애니메이션
- active: scale(0.97) + 글로우 강화
- variant prop: 'primary'(cyan) | 'danger'(red) | 'gold' — 네온 색상 결정
- size prop: 'sm' | 'md' | 'lg'
- children, onClick, disabled, className prop
- disabled 상태: opacity 0.4, 애니메이션 없음
```

**barrel export:** `apps/web/src/components/game/ui/index.ts`

**공통 규칙:**
- 모든 컴포넌트는 `useFunMode()` 훅으로 반전 모드 확인하지 않음 — 이 컴포넌트들은 반전 모드 전용이므로 호출하는 쪽에서 조건 분기
- Tailwind v4 유틸리티 + CSS 변수 조합 사용
- Framer Motion은 필요한 곳만 (GlassCard hover, LaserButton active)
- 이모지 절대 금지
