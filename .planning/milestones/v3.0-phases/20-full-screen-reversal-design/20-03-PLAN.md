## 1. MonsterSvg 컴포넌트

`apps/web/src/components/wrong-notes/MonsterSvg.tsx` 생성:
- 문제 유형별 기하학적/수학 모티프 몬스터 실루엣 SVG
- 유형 매핑 (6종):
  - '수와연산': 다면체 형태 몬스터 (정이십면체 모티프)
  - '도형': 삼각형/사각형 조합 몬스터 (기하 모티프)
  - '측정': 자/컴퍼스 형태 몬스터
  - '규칙성': 프랙탈/패턴 형태 몬스터
  - '자료와가능성': 그래프/차트 형태 몬스터
  - 'default': 물음표 형태 기본 몬스터
- **난이도별 등급 시각화:**
  - 일반(쉬움): 회색 실루엣 + 얇은 보더
  - 고급(보통): cyan 네온 + 글로우
  - 보스(어려움): red/magenta 네온 + 강한 글로우 + pulse 애니메이션
- Props: type (문제유형), difficulty (난이도), defeated (정답 여부), size
- defeated=true: 풀 컬러 + 체크마크 오버레이
- defeated=false: 어둡게 + 눈만 빛나는 실루엣
