# Phase 20: 전체 화면 반전 디자인 - Context

**Gathered:** 2026-02-23
**Status:** Ready for planning

<domain>
## Phase Boundary

반전 모드(FunMode)에서 모든 주요 화면(홈, 퀴즈, 분석, 오답노트, 문제집, 강사 포털, 마이페이지)을 일관된 게임 테마 디자인으로 변환. 기존 Phase 15~19에서 구축한 인프라/컴포넌트를 활용하여 화면별 비주얼 테마 적용. 일반 모드 복원 100% 보장.

</domain>

<decisions>
## Implementation Decisions

### 디자인 원칙 (유저 피드백 반영)
- 어두운 배경 + 밝은 글자 — 게임모드에서도 가독성 최우선
- 화려하고 레이저 효과 느낌 — 네온/글로우 강조선, 그라데이션 테두리
- 이모지 절대 금지 — 모든 아이콘은 SVG 커스텀 아이콘 사용 (고퀄리티)
- 일관된 컬러 팔레트: 다크 배경(#0a0a1a ~ #1a1a2e), 네온 악센트(cyan #00d4ff, magenta #ff00ff, gold #ffd700)
- 카드/패널: 반투명 글래스모피즘 (backdrop-blur + border gradient)

### 홈 화면 게임 대시보드 (SCRN-01)
- XP 바, 레벨, 스트릭 카운터, 데일리 챌린지가 "게임 HUD" 형태로 배치
- 기존 Phase 16 위젯 재사용 + 다크 테마 스타일 오버라이드
- 게임 모드 퀵 런처 카드 (타임어택/서바이벌/보스배틀/미니게임)
- 리더보드 미니 위젯 (TOP 3)

### 퀴즈 화면 게임 HUD (SCRN-02)
- HP 바(서바이벌/보스배틀), 콤보 카운터, 타이머가 게임 오버레이 형태
- 문제 카드: 네온 테두리 + 글로우 효과
- 선택지 버튼: 호버 시 레이저 라인 강조
- 기존 Phase 19 게임 모드 컴포넌트의 스타일 일관화

### 오답노트 몬스터 도감 (SCRN-03)
- 틀린 문제 = "잡아야 할 몬스터" 카드로 표시
- 각 문제 유형에 대응하는 SVG 몬스터 실루엣 (기하학적/수학 모티프)
- 몬스터 도감 그리드 레이아웃 — 잡은 몬스터(정답 후) vs 미처치(아직 틀린 채)
- 난이도별 몬스터 등급: 일반(회색), 고급(파랑), 보스(빨강)
- 몬스터 클릭 → 해당 문제 상세 + "재도전" 버튼

### 마이페이지 캐릭터 프로필 (SCRN-04)
- RPG 캐릭터 시트 스타일: 레벨, 총 XP, 능력치(정확도/속도/스트릭)
- 뱃지 진열장: 카테고리별 슬롯 그리드 (획득/미획득 시각적 구분)
- 업적 현황: 진행 바 + 다음 업적까지 남은 수치
- 기존 Phase 16 프로필 뱃지 패널 확장

### 분석 대시보드 + 기타 화면 (SCRN-05~07)
- 분석: 차트/그래프에 네온 라인 + 다크 배경 적용
- 문제집: 카드 디자인에 게임 테마 스타일 오버라이드
- 강사 포털: 최소한의 테마 변경 (강사는 게임 몰입보다 관리 효율 중시)

### CSS 변수 전략
- Phase 15에서 구축한 [data-fun-mode='true'] CSS 변수 오버라이드 확장
- 기존 Tailwind 유틸리티에 게임 테마 전용 커스텀 속성 추가
- 전환 시 즉시 복원 보장 (CSS 변수 초기화로 일반 모드 즉시 복귀)

### SVG 아이콘 시스템
- 게임 테마 전용 SVG 아이콘 세트 생성 (검, 방패, 하트, 별, 몬스터 등)
- React 컴포넌트로 래핑 (색상/크기 prop)
- 이모지 사용 부분 전부 SVG로 교체 (Phase 16~19 포함)

### Claude's Discretion
- 정확한 CSS 변수 값 (그라데이션 각도, 블러 강도 등)
- SVG 아이콘 디테일 수준
- 화면별 세부 레이아웃 조정
- 애니메이션 타이밍/이징 값
- 몬스터 SVG 디자인 디테일
- 강사 포털 테마 적용 범위

</decisions>

## Specific Ideas

- "레이저" 느낌: 네온 글로우 보더(box-shadow: 0 0 10px cyan), 움직이는 그라데이션 보더
- 글래스모피즘 카드: background rgba(255,255,255,0.05) + backdrop-blur-md + border rgba(255,255,255,0.1)
- 몬스터 도감: 포켓몬 도감 레퍼런스 — 격자형 카드, 잡은/안잡은 실루엣 구분
- RPG 프로필: 게임 캐릭터 스탯 시트 레퍼런스 — 육각형 능력치 차트

</specifics>
