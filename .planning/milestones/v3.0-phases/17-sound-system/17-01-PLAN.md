**2. SoundManager.ts (React 외부 싱글턴):**
- 파일 위치: `apps/web/src/lib/sound/SoundManager.ts`
- `import { Howl, Howler } from 'howler'`
- 클래스 패턴: private constructor + static getInstance()
- 내부 상태: `_bgmEnabled: boolean = false`, `_bgmVolume: number = 0.5`, `_sfxVolume: number = 0.7`, `_isMuted: boolean = false`, `bgm: Howl | null = null`
- 메서드:
  - `loadBGM(src: string)`: 이전 BGM `unload()` 후 새 Howl 생성. `{ html5: true, loop: true, volume: this._bgmVolume, autoplay: false }`
  - `toggleBGM(): boolean`: bgmEnabled 토글. ON이면 `play()`, OFF면 `pause()`. iOS 안전장치: `Howler.ctx?.state === 'suspended'` → `Howler.ctx.resume()`
  - `setBGMVolume(vol: number)`: 0~1 범위 클램핑, `this.bgm?.volume(vol)`
  - `setSFXVolume(vol: number)`: _sfxVolume 저장만 (SfxEngine에서 읽음)
  - `toggleMute(): boolean`: `Howler.mute(!this._isMuted)`
  - `applySettings(settings)`: Dexie에서 로드한 설정 일괄 적용
  - `subscribe(listener)`: 상태 변경 구독 (React useSyncExternalStore용). 반환값: unsubscribe 함수
  - `getSnapshot()`: 현재 상태 객체 반환 `{ bgmEnabled, bgmVolume, sfxVolume, isMuted }`
  - `dispose()`: bgm?.unload(), 인스턴스 null 처리
- `onplayerror` 핸들러: `sound.once('unlock', () => sound.play())` — iOS 잠금 해제 실패 시 재시도
- export: `export const soundManager = SoundManager.getInstance()`

**3. SfxEngine.ts (Web Audio API 프로그래매틱 합성):**
- 파일 위치: `apps/web/src/lib/sound/SfxEngine.ts`
- `import { Howler } from 'howler'` — Howler.ctx로 AudioContext 공유 (직접 생성 금지)
- `SfxType = 'correct' | 'wrong' | 'combo' | 'levelUp' | 'badge' | 'streak'`
- 클래스 패턴: SfxEngine 싱글턴 (soundManager와 동일 패턴)
- 내부에서 soundManager.sfxVolume 접근하여 볼륨 적용
- 메서드:
  - `play(type: SfxType, options?: { comboStep?: number })`: AudioContext가 없거나 suspended면 무음 return (무음 fallback)
  - 각 타입별 합성 로직:
    - `correct`: sine wave, C6(1046.5Hz) → E6(1318.5Hz), 0.3초, gain exponential ramp to 0.001
    - `wrong`: triangle wave, 300Hz → 150Hz 하강, 0.3초
    - `combo`: sine wave, 피치 = comboStep별 (2=880Hz, 3-4=880*1.2, 5+=880*2), 정답음 + 추가 상승 0.4초
    - `levelUp`: 3음 arpeggio (C5→E5→G5→C6), 각 0.3초 간격, 총 1.5초. 팡파르 느낌.
    - `badge`: 2음 chime (E5→A5), 0.5초 + 0.5초 = 1초
    - `streak`: 밝은 코인음 — square wave C6, 짧은 decay 0.5초
  - 합성 헬퍼: `private createOscNode(type, freq, startTime, duration)` — 중복 코드 방지
- export: `export const sfxEngine = SfxEngine.getInstance()`
