  1. **MiniGameRegistry.ts — 미니게임 등록/조회 패턴:**
     ```typescript
     export interface MiniGameConfig {
       key: string            // 고유 키 (예: 'formulaCombo')
       name: string           // 표시 이름 (예: '수식 조합')
       description: string    // 간단한 설명
       sceneFactory: () => Promise<{ default: new (key: string) => Phaser.Scene }>
     }
     ```
     - `registerMiniGame(config: MiniGameConfig)` — 레지스트리에 등록
     - `getMiniGames(): MiniGameConfig[]` — 전체 목록
     - `getMiniGame(key: string): MiniGameConfig | undefined` — 단건 조회
     - 초기 등록:
       ```typescript
       registerMiniGame({
         key: 'formulaCombo',
         name: '수식 조합',
         description: '떨어지는 숫자와 연산자를 조합하여 목표 값을 만드세요',
         sceneFactory: () => import('./scenes/FormulaComboScene'),
       })
       ```

  2. **EventBus.ts 이벤트 타입 확장:**
     - 기존 SimpleEventEmitter 유지 (Phaser.Events.EventEmitter 교체는 향후)
     - 미니게임 이벤트 명세 (주석으로 문서화):
       - 'minigame-score-update': { score: number }
       - 'minigame-complete': { score: number, xp: number, success: boolean }
       - 'minigame-ready': null

  3. **MiniGameBridge.tsx — PhaserBridge 확장:**
     - Phase 15 PhaserBridge.tsx 패턴 기반 (useRef 가드 + dynamic import + cleanup)
     - Props: miniGameKey (string), width (기본 400), height (기본 500), onComplete (result) => void
     - 동작 흐름:
       1. MiniGameRegistry에서 miniGameKey로 config 조회
       2. config.sceneFactory() 로 Phaser Scene 동적 import
       3. Phaser.Game 생성 (dynamic import('phaser'))
       4. 씬 등록 + 시작
       5. EventBus 리스너 등록: 'minigame-complete' → onComplete 호출
       6. cleanup: game.destroy(true) + EventBus.off()
     - WebGL 컨텍스트 관리: Phaser.CANVAS 모드 사용 (Three.js와 동시 실행 시 안전)
       또는 미니게임 진입 시 ThreeBackground 일시 비활성화
     - GameLoadingSpinner 표시 (Phase 15 패턴 재사용)

  4. **FormulaComboScene.ts — 수식 조합 미니게임 Phaser 씬:**
     - Phaser.Scene 확장 클래스
     - **게임 규칙:**
       - 화면 상단에서 숫자(1~9)와 연산자(+, -, x)가 떨어짐
       - 화면 하단에 "슬롯" 3개 (숫자-연산자-숫자)
       - 목표: 떨어지는 요소를 터치/클릭하여 슬롯에 배치, 결과가 목표값과 일치하면 점수
       - 목표값은 좌상단에 표시 (예: "= 7")
     - **Phaser 구현:**
       - preload: 간단한 원형/사각형 그래픽 (Phaser Graphics, 외부 에셋 불필요)
       - create: 슬롯 UI + 목표값 텍스트 + 점수 텍스트
       - update: 요소 떨어지는 로직 (y += speed * delta)
       - 터치/클릭: 떨어지는 요소 클릭 → 빈 슬롯에 배치
       - 3슬롯 채워지면 자동 계산 → 정답이면 점수+100, 오답이면 슬롯 초기화
       - 30초 타이머 (Phaser.Time.TimerEvent)
       - 게임 종료: EventBus.emit('minigame-complete', { score, xp: Math.round(score / 10), success: score >= 300 })
     - **난이도 곡선:** 시간이 지날수록 떨어지는 속도 증가 (speed = 50 + elapsed * 2)
     - **시각 스타일:** 어두운 배경(#1a0a2e), 네온 색상 텍스트, 기하학적 요소

  5. **MiniGameMode.tsx — 미니게임 모드 React 래퍼:**
     - Props: studentId (string), onComplete (result) => void, onBack () => void
     - 미니게임 선택 UI (현재는 1종이므로 바로 시작)
     - MiniGameBridge 렌더링
     - 완료 시 GameResult 화면으로 전환 (score → GameResult props 매핑)
     - XP 지급: awardXP(xp, 'minigame_complete')
