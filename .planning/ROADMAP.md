## Phase Details

### Phase 15: 반전 모드 기반 인프라 + 번들 전략

**목표**: 사용자가 커스터마이즈 버튼 클릭 한 번으로 전체 앱이 게임 모드로 전환되며, 일반 모드 초기 로딩 성능에 전혀 영향을 주지 않아야 한다
**의존성**: Phase 14 (v2.0 완료)
**요구사항**: INFRA-01, INFRA-02, INFRA-03, INFRA-04, INFRA-05
**성공 기준** (사용자가 관찰할 수 있는 동작):
  1. 사용자가 커스터마이즈 버튼을 클릭하면 전체 UI 테마가 즉시(애니메이션과 함께) 게임 스타일로 전환된다
  2. 반전 모드로 전환 후 페이지를 새로고침하거나 재접속해도 게임 모드가 유지된다
  3. 반전 모드 최초 진입 시 재미있는 로딩 화면이 표시되며, 게임 에셋 로드 진행률을 확인할 수 있다
  4. 일반 모드에서 앱을 열 때 Phaser/Three.js/Howler.js 관련 코드가 번들에 포함되지 않아 초기 로딩이 빠르다
  5. 반전 모드와 일반 모드 간 전환을 10회 반복해도 앱이 정상 동작하며 메모리 오류가 발생하지 않는다
**계획**: 3 plans

Plans:
- [ ] 15-01-PLAN.md — FunModeContext + CSS 테마 변수 + 커스터마이즈 토글 버튼
- [ ] 15-02-PLAN.md — Vite manualChunks 번들 분리 + GameLoadingSpinner + FunModeGate
- [ ] 15-03-PLAN.md — Dexie v8 마이그레이션 + Phaser POC 검증 + 인간 체크포인트

### Phase 16: 보상 시스템

**목표**: 사용자가 문제를 풀 때마다 즉각적인 XP 보상을 받고, 누적 성취(레벨, 스트릭, 뱃지)와 경쟁(리더보드, 챌린지)을 통해 학습 동기가 지속적으로 유지되어야 한다
**의존성**: Phase 15
**요구사항**: RWRD-01, RWRD-02, RWRD-03, RWRD-04, RWRD-05, RWRD-06, RWRD-07, RWRD-08
**성공 기준** (사용자가 관찰할 수 있는 동작):
  1. 문제를 풀면 획득한 XP가 화면의 XP 바에 실시간으로 채워지는 애니메이션이 재생된다
  2. 연속 정답 시 화면에 "2x 콤보!", "3x 콤보!" 등 콤보 카운터가 표시되고, 콤보에 비례해 더 많은 XP를 획득한다
  3. 매일 학습하면 홈 화면에 스트릭 카운터가 증가하고, 스트릭 보너스 XP를 획득한 기록이 남는다
  4. 뱃지 달성 조건을 충족하면 뱃지 획득 알림이 표시되고 마이페이지 프로필에서 확인할 수 있다
  5. 반 내 리더보드에서 자신의 현재 XP 순위와 상위/하위 학생과의 격차를 확인할 수 있다
**계획**: 미정

### Phase 17: 사운드 시스템

**목표**: 반전 모드에서 정답/오답/레벨업 등 모든 주요 이벤트에 즉각적인 청각 피드백이 제공되며, 사용자가 사운드 환경을 완전히 제어할 수 있어야 한다
**의존성**: Phase 15
**요구사항**: SND-01, SND-02, SND-03, SND-04, SND-05
**성공 기준** (사용자가 관찰할 수 있는 동작):
  1. 반전 모드 진입 시 BGM이 기본값 OFF 상태이며, 사용자가 BGM 토글 버튼을 눌러야 음악이 재생된다
  2. 정답/오답/콤보/레벨업 시 각각 구별되는 효과음이 즉시 재생된다
  3. 설정 화면에서 BGM 볼륨과 효과음 볼륨을 개별적으로 슬라이더로 조절할 수 있다
  4. iPhone(iOS)에서 처음 커스터마이즈 버튼을 탭하면 이후 모든 사운드가 정상적으로 재생된다
**계획**: 미정

### Phase 18: Three.js 시각 효과

**목표**: 반전 모드에서 3D 배경과 파티클 이펙트가 학습 이벤트(정답, 오답, 레벨업, 콤보, 퀴즈 완료)에 즉각적으로 반응하며, 저사양 기기에서도 앱이 정상 동작해야 한다
**의존성**: Phase 15 (WebGL 컨텍스트 예산 확정 후)
**요구사항**: VFX-01, VFX-02, VFX-03, VFX-04, VFX-05, VFX-06, VFX-07
**성공 기준** (사용자가 관찰할 수 있는 동작):
  1. 반전 모드에서 각 화면(홈, 퀴즈, 분석 등)마다 서로 다른 테마의 3D 배경 애니메이션이 표시된다
  2. 정답 제출 시 화면에 파티클 폭발 이펙트가 즉시 재생된다
  3. 오답 제출 시 화면이 흔들리며 빨간 플래시가 번쩍인다
  4. 레벨업 시 풀스크린 시네마틱 연출이 재생된 후 새 레벨 정보가 표시된다
  5. 퀴즈 완료 시 컨페티(종이 조각) 축하 애니메이션이 화면에 쏟아진다
**계획**: 미정

### Phase 19: 게임화 퀴즈 엔진

**목표**: 사용자가 타임어택, 서바이벌, 보스배틀, 미니게임이라는 4가지 게임 모드 중 원하는 방식으로 수학 문제를 풀 수 있으며, 각 모드 완료 후 획득한 점수와 XP를 확인할 수 있어야 한다
**의존성**: Phase 16 (XP 시스템), Phase 17 (사운드), Phase 18 (시각 효과)
**요구사항**: GAME-01, GAME-02, GAME-03, GAME-04, GAME-05, GAME-06
**성공 기준** (사용자가 관찰할 수 있는 동작):
  1. 타임어택 모드에서 화면 상단의 카운트다운 타이머가 줄어드는 가운데 문제를 연속으로 풀 수 있다
  2. 서바이벌 모드에서 화면에 하트 3개가 표시되며, 오답 시 하트가 하나씩 사라지고 0개가 되면 게임오버 화면이 뜬다
  3. 보스 배틀 모드에서 보스 HP 바가 표시되며, 정답 시 보스가 공격받는 애니메이션이 재생되고 오답 시 플레이어가 공격받는 애니메이션이 재생된다
  4. 각 게임 모드 종료 후 결과 화면에서 획득 점수, XP 획득량, 개인 최고기록 달성 여부를 확인할 수 있다
  5. Canvas 기반 미니게임(수식 조합 등) 화면이 열리고 사용자가 인터랙션하여 플레이할 수 있다
**계획**: 미정

### Phase 20: 전체 화면 반전 디자인

**목표**: 반전 모드에서 앱의 모든 주요 화면(홈, 퀴즈, 분석, 오답노트, 문제집, 강사 포털, 마이페이지)이 일관된 게임 테마 디자인으로 완전히 변신하여 몰입감 있는 게임 학습 경험을 제공해야 한다
**의존성**: Phase 15, Phase 16 (XP/레벨 UI 데이터), Phase 18 (시각 효과)
**요구사항**: SCRN-01, SCRN-02, SCRN-03, SCRN-04, SCRN-05, SCRN-06, SCRN-07
**성공 기준** (사용자가 관찰할 수 있는 동작):
  1. 반전 모드 홈 화면에 XP 바, 현재 레벨, 스트릭 카운터, 데일리 챌린지 위젯이 게임 대시보드 스타일로 표시된다
  2. 반전 모드 퀴즈 화면에 HP 바, 콤보 카운터, 타이머가 게임 HUD 형태로 오버레이된다
  3. 반전 모드 오답노트 화면에서 틀린 문제가 "잡아야 할 몬스터"로 표시되며 몬스터 도감 스타일 UI로 볼 수 있다
  4. 반전 모드 마이페이지에서 캐릭터 프로필 스타일로 레벨, 획득 뱃지 목록, 업적 현황을 확인할 수 있다
  5. 반전 모드를 끄면 모든 화면이 즉시 기존 일반 모드 디자인으로 복원된다
**계획**: 미정
